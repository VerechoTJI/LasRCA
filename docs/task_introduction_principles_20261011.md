## 沿用結構時需要更正的內容

1. 第17頁notes把Macro F1說成Macro Precision／Recall的調和平均，但本次公開程式使用逐類F1平均。新草稿採實際evaluator定義，並記錄與論文文字的差異，不複製舊定義。
2. 第2頁將TS2Vec項目描述為released checkpoint。下載包核對證明作者提供 `embedding_600.pkl` 與下游模型，沒有TS2Vec encoder權重。新草稿明確區分模型參數與已算好的向量。
3. 第30頁的682 entity occurrences是舊選樣執行結果。本輪Luna標註報告的分母為653，不能把不同run的數字混用。本輪依使用者要求沿用指定的100 cases／subgraphs，草稿只引用本輪證據。
4. 第2、32頁的Not started／Future Work是2026-09-29簡報的歷史狀態。新草稿用任務目標介紹已完成的工作，最新實驗狀態以2026-10-05結案及encoder追加對照為準。
